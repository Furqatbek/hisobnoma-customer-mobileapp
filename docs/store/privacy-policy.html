Sheben N1 — Махфийлик сиёсати

Амал қилиш санаси: 2026-08-20 · TEMUR MCHJ, Тошкент, Ўзбекистон

Ушбу ҳужжат «Sheben N1» мобил иловаси (бундан кейин — «Илова») фойдаланувчиларининг маълумотлари қандай тўпланиши ва ишлатилишини тушунтиради. Илова эгаси — TEMUR MCHJ (бундан кейин — «Биз»).

Қандай маълумотлар тўпланади

  • Телефон рақами — SMS орқали кириш ва буюртма бўйича боғланиш учун.
  • Исм — буюртмани расмийлаштириш учун.
  • Етказиб бериш манзили (туман, маҳалла, кўча) — буюртмани етказиш учун.
  • Буюртмалар тарихи ва кешбек баланси — хизмат кўрсатиш учун.

Илова жойлашувингизни кузатмайди, контактларингизни ўқимайди ва реклама идентификаторларидан фойдаланмайди. Тўлов ҳозирча етказиб берилганда нақд пулда амалга оширилади — банк карта маълумотлари тўпланмайди.

Маълумотлар ким билан улашилади

  • SMS-код юбориш учун SMS-провайдерга телефон рақами узатилади.
  • Етказиб бериш ходимларига буюртма учун зарур исм, телефон ва манзил кўрсатилади.
  • Онлайн тўлов ишга туширилганда тўлов провайдерига (Payme/Click) фақат тўлов учун зарур маълумотлар узатилади.

Маълумотлар учинчи шахсларга сотилмайди ва реклама мақсадида улашилмайди.

Сақлаш ва хавфсизлик

Барча алоқа HTTPS орқали шифрланади. Кириш токени қурилманинг ҳимояланган хотирасида сақланади. Маълумотлар хизмат кўрсатиш учун зарур муддат давомида сақланади.

Ҳуқуқларингиз

Аккаунтингиз ва у билан боғлиқ маълумотларни ўчиришни сўраш, маълумотларингиз ҳақида маълумот олиш учун қуйидаги манзилга мурожаат қилинг. Сўровлар 30 кун ичида кўриб чиқилади.

Болалар

Илова 18 ёшдан катта фойдаланувчиларга мўлжалланган.

Sheben N1 — Политика конфиденциальности

Дата вступления в силу: 2026-08-20 · TEMUR MCHJ, Ташкент, Узбекистан

Этот документ описывает, какие данные собирает мобильное приложение «Sheben N1» (далее — «Приложение») и как они используются. Владелец Приложения — TEMUR MCHJ (далее — «Мы»).

Какие данные собираются

  • Номер телефона — для входа по SMS и связи по заказу.
  • Имя — для оформления заказа.
  • Адрес доставки (район, махалля, улица) — для доставки заказа.
  • История заказов и баланс кешбэка — для оказания услуг.

Приложение не отслеживает геолокацию, не читает контакты и не использует рекламные идентификаторы. Оплата пока производится наличными при получении — данные банковских карт не собираются.

С кем данные передаются

  • SMS-провайдеру — номер телефона для отправки кода входа.
  • Службе доставки — имя, телефон и адрес, необходимые для заказа.
  • После запуска онлайн-оплаты — платёжному провайдеру (Payme/Click) только данные, необходимые для платежа.

Данные не продаются третьим лицам и не передаются в рекламных целях.

Хранение и безопасность

Вся связь шифруется по HTTPS. Токен входа хранится в защищённом хранилище устройства. Данные хранятся столько, сколько необходимо для оказания услуг.
